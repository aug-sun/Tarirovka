# Тарировка Бак-Контроль

Flutter-приложение для создания паспортов сертификатов тарировки топливных баков.

 **Сборка и запуск**
   ```bash
   flutter pub get
   flutter run
   ```
   Для релизной сборки:
   ```bash
   flutter build apk --release
   ```

## Экспорт файлов

PDF и CSV сохраняются в стандартную папку **Documents/Tarirovka** на внешнем хранилище Android.  
Если папка недоступна (например, из-за ограничений системы), используется внутренняя память приложения.

## Настройки

- **Раздельный импорт** — в настройках можно включить отдельные кнопки экспорта PDF и CSV.
- **Темная тема** — переключатель в настройках.
- **Сброс данных** — полное удаление всех тарировок и настроек.
